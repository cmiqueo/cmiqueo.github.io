Card Metadata Bookmarklet

Drag the button below to your bookmarks bar to install it:

Card Metadata

If dragging doesn't work, right-click the button and choose "Bookmark Link" / "Add Bookmark", or create a new bookmark manually and paste the link's URL.

What it does

Run it on an authored page containing a .card-metadata block. It shows a floating panel with the page's Chimera UUID (linked to the Chimera collection API for debugging) and the parsed card metadata (title, description, tags, images, etc.).

A new popup window will show the card UUID and the card metadata if available.
