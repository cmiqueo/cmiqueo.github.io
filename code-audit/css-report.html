1. Summary

Measured against SUIT CSS, the codebase is largely compliant — this is effectively the standard the project already follows. The infobits, filters, core widgets (bookmarks, filters-info, load-more, loader, search, tooltip), and the original card infrastructure (card, card-footer, link-blocker) are Consistent.

Deviations cluster in three places: (1) kebab-case variant classes chained onto .consonant-Card (.three-fourths, .one-half, .full-card…) that SUIT would model as --camelCase modifiers; (2) the legacy references/ and utils/ helper libraries, which use presentational, un-prefixed names instead of SUIT u- utilities; and (3) newer bolt-on features (.modern-carousel, categories.less, blade/editorial/flex) with presentational names, hardcoded colors, and raw-px breakpoints.

Bottom line: the naming spine is already SUIT-shaped, so fixes are targeted rather than a migration — standard-agnostic selector bugs remain the top priority.

2. Systemic & Recurring Issues

  1. Kebab variant classes chained on the block instead of --camelCase modifiers. .consonant-Card.three-fourths, .one-half, .full-card, .news-card, .text-card, .half-height, .double-wide, .product, .icon-card, .blog-card. SUIT wants .consonant-Card--threeFourths. Consistent internally, but a systematic deviation across every card file.
  2. Legacy utilities ignore the SUIT u- prefix. The codebase uses u- correctly in one place (.consonant-u-themeLight) but references//utils/ define presentational, un-prefixed helpers: .left, .no-margin, .full-width, .hide-all, .NoMargin/.NoMarginTop (also PascalCase, so they read as components).
  3. Presentational class names. .modern-carousel, .card-hover-grow, .light-text, .reverse, .transparent, .text-left/-center/-right, &.lightText (pagination), &.sort-by-Select (select), .filters-category/.filter-group-title (kebab not PascalCase), .Categories (drops the consonant- namespace).
  4. Hardcoded hex/rgba colors instead of tokens. cards-carousel .modern-carousel (~15), categories (~14), blade, editorial, button, flex (#333/#666), pagination/select (#999/#ccc/#aaa), accessibility (#dedede), filters/left/panel (#eaeaea/#fff), filters/top/*.
  5. Two competing color-variable systems. cards/icon.less and cards/horizontal.less use the static @consonantLightGrey*/@consonantDarkGrey* palette instead of themeable @consonantGray* → ignore theming.
  6. Raw-px / arithmetic media queries bypass named queries: cards-carousel (599px + 1), cards-grid (320/600), categories (480), blade (1200/600). utils/hide.less references two undefined vars (@for-tablet-portrait-up, @for-desktop-up).
  7. Duplicated helpers & dead code. .no-font/.margin-auto/.full-width/.hide-all defined in both utils//references/ and components/consonant/utils.less; .hide-all 3× in hide.less; dead blocks in lineclamp:15-37, utils.less, filters/left/item:476.
  8. Genuine selector bugs (standard-agnostic). &-descendant misuse in variant scopes (three-fourth:90, text:87, double-wide:136,140,150,154, editorial:22-26); bare :only-child (half-height:92,143, double-wide:51,87); missing comma in search.less:57-59; typos --83PercentContainier, &-selctedItemsQty; mis-scoped leaks in news:26-51, three-fourth:241.
  9. Formatting drift in the category/nested-filter feature: filters/left/item.less and filters/top/item.less use // comments, near-empty placeholder rule bodies, and a raw &-categoryIcon hardcoding font props instead of the .font() mixin.

4. Recommendations

Because the codebase is already SUIT-shaped, these are targeted fixes rather than a migration — ordered by impact.

Priority 1 — Correctness (broken/dead rules; fix regardless of standard)

  • Fix &-descendant-in-variant selectors: three-fourth:90, text:87, double-wide:136,140,150,154, editorial:22-26 (use the full .consonant-Card-x).
  • Fix bare :only-child (add &) in half-height:92,143 and double-wide:51,87.
  • Fix the missing comma in search.less:57-59 transition list.
  • Re-scope news:26-51 and three-fourth:241 so they don't leak to all cards.
  • Fix typos wrapper.less --83PercentContainier, rtl.less:170 &-selctedItemsQty.
  • Define or remove the undefined @for-* vars in utils/hide.less.
  • Correct invalid values: type.less:27 font-weight:light, main.less:31 outline shorthand, card.less:83 border:2px.

Priority 2 — SUIT naming alignment

  • Promote chained kebab card variants to --camelCase modifiers: .consonant-Card.three-fourths → .consonant-Card--threeFourths, and likewise one-half, full-card, news-card, text-card, half-height, double-wide, product, icon-card, blog-card. Coordinate with the JS/AEM markup that applies these classes — cross-surface rename.
  • Move legacy references//utils/ helpers behind the SUIT u- prefix (.u-hidden, .u-fullWidth, .u-marginAuto…) and drop presentational names (.left, .NoMarginTop).
  • Rename presentational classes to states/modifiers: &.lightText→.is-*/--withLightText (pagination), .light-text/.reverse/.transparent (blade), .text-* (flex), &.sort-by-Select (select); namespace .Categories and PascalCase .filters-category.

Priority 3 — Theming & breakpoints

  • Move cards/icon.less and cards/horizontal.less onto themeable @consonantGray*/@consonantBaseColor.
  • Replace hardcoded hex/rgba in cards-carousel, categories, blade, editorial, button, flex, filters/*, pagination, select, accessibility with tokens.
  • Replace raw-px/arithmetic media queries in cards-carousel, cards-grid, categories, blade with named @consonant-*-up queries.

Priority 4 — Hygiene

  • De-duplicate helpers across utils//references//components/consonant/utils.less.
  • Unify the category/nested-filter block in filters/left/item.less and filters/top/item.less: /* */ comments, remove empty placeholder rules, use .font() for &-categoryIcon.
  • Remove dead commented blocks (lineclamp:15-37, utils.less, filters/left/item:476); resolve the categories.less "should be moved" TODO; exclude vendor modal.less from future audits.
