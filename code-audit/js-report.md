# JS Audit Report

**Project:** Adobe CaaS (Consonant Card Collection)
**Scope:** Authored JavaScript/JSX under `react/src/js/` (108 files; `__tests__/`, `__test__/`, `*.test.js`, `Testing/`, `dist/`, `node_modules/` excluded)
**Date:** 2026-07-29
**Lens:** Airbnb / ESLint style guide (as configured in this project — the `Consonant/**` override and global rule disables were honored; disabled rules such as `no-console`, `max-len`, `no-plusplus`, `exhaustive-deps`, and the subtree's formatting rules are **not** flagged)

## 1. Summary

Against the project's _configured_ Airbnb ruleset, the codebase is **broadly clean and internally consistent** — 56 of 108 files are Consistent, 17 are N/A (PropTypes shapes, constants, contexts, test fixtures, and vendored `@dexter/` code), and only 9 are Inconsistent. The React component tree is disciplined: every component declares `propTypes`, `defaultProps` are paired wherever a prop isn't required, hooks are called unconditionally, and there is essentially no `var`, no loose `==`, no unused/duplicate imports, and no array-index keys anywhere in the authored components. The real problems cluster in two areas: (1) **entry/Modal utility files that ship blanket `/* eslint-disable */` headers, empty dead files, and commented-out or debug code** (`app.jsx`, `modal.js`, `Modal/Icon.js`, `index.js`, `polyfills.js`), and (2) a repeated **`key={cuid()}` anti-pattern** that mints a fresh React key every render. A handful of genuine latent bugs surfaced from close reading (a mis-typed config path, a double `Date.parse`, a permanently-dead debounce guard) matter more than any style nit.

## 2. Systemic & Recurring Issues

1. **`key={cuid()}` defeats React reconciliation.** A brand-new random key is generated every render, so React remounts the whole list each time (losing DOM/focus state, hurting perf). Worse than the `no-array-index-key` it sidesteps. Recurs in `Infobit/Group.jsx` (13 branches), `Helpers/rendering.js` (5 sites), and every card that maps a footer (`BladeCard`, `BlogCard`, `EditorialCard`, `FlexCard`, `NewsCard`, `OneHalf`, `Product`, `TextCard`). Highest-value fix.

2. **Blanket `/* eslint-disable */` on authored, non-trivial files.** `app.jsx`, `Modal/modal.js` (~377 lines), and `Helpers/eventSort.js`/`Helpers/hooks.js` (legacy `var` code) suppress the entire ruleset rather than the specific rule/line — hiding real issues in production code. Distinct from the transpiled `@dexter/` artifacts, where it's expected.

3. **Dead files and commented-out / debug code shipping in source.** Empty 0-byte files `Modal/Icon.js` and `index.js` (neither imported anywhere); `polyfills.js` is ~70 lines of fully commented-out imports yet still `import`ed by `app.jsx`; `app.jsx` computes a "Babel 7 Upgrade Verified 🎉" object solely to `console.log` it; commented-out blocks in `Container.jsx`, `Grid.jsx`, `eventSort.js`, and stray `// here` markers in `withLinkTransformer.js`.

4. **Latent correctness bugs (not style).** `Helpers/JsonProcessor.js:92` reads mis-typed path `contentArea.dateTetailText` (always resolves to `''`); `Helpers/general.js:569` double-wraps `Date.parse(Date.parse(...) - currentDate)` → always `NaN`, dead branch; `Modal/throttle.js` re-declares `timeout` each call so the `if (timeout) clearTimeout` guard is permanently dead (debounce doesn't work); `CardFooter.jsx` guards on `if (new Date(cardDate))` which is always truthy; `Helpers/eventSort.js:127` returns an array where all other paths return an object.

5. **In-place mutation of state/config/inputs.** `Container.jsx` mutates prior state in `setFilters` (`prevFilters.pop()/.push()`) and mutates the config-derived `authoredFilters` objects; `Helpers/Helpers.js` sort helpers mutate the caller's array via `.sort()`; `CardsCarousel.jsx` uses module-level mutable `let cardWidth`/`cardsShiftedPerClick` shared across instances.

6. **`CardFooter.jsx` propTypes/defaultProps badly lag its prop surface.** It validates only `footerType`'s 5 fields while consuming `altRight, cardDate, startDate, endDate, onFocus, title, tabIndex, renderOverlay, hideCTA, isBlog, isFlexCard, showDateOnFooter`. Related: several panels pass props their children don't declare (`panelHeader`→`ClearButton`; `isOpened`/`onClick`/`isTopFilter`→`Group`).

7. **Redundant `eslint-disable` directives.** Many inline suppressions target rules this config already turns off globally (`max-len`, `no-restricted-syntax`, `no-plusplus`) — dead directives; `eslint --report-unused-disable-directives` would surface them.

8. **Cosmetic consistency drift (low severity).** Redundant `tabIndex="0"` on native `<button>`s; mixed `tabIndex` string `"0"` vs numeric `{0}` (`Sort/Popup.jsx`); `forwardRef` components without `displayName` (five Filters files); copy-paste JSDoc drift (`Icon.jsx` header, `Rating.jsx`/`Search.jsx` `@param`s); a few hardcoded English aria strings in an otherwise i18n-driven tree.

## 4. Recommendations

**Priority 1 — Correctness (real bugs; fix regardless of style):**

- `Helpers/JsonProcessor.js:92` — fix mis-typed path `dateTetailText` → `dateDetailText`.
- `Helpers/general.js:569` — remove the double `Date.parse`; `endPriority` is always `NaN`.
- `Modal/throttle.js` — move `let timeout` outside the returned closure so the debounce guard actually works; fix `default-param-last`.
- `CardFooter.jsx:143,152` — the `if (new Date(cardDate))` guard is always truthy; validate the date properly.
- `Helpers/eventSort.js:127` — return the `{ visibleSessions, nextTransitionMs }` shape on the empty-input path (callers destructure it).
- `Grid.jsx:255` — add a `key` to the `CARD_STYLES.CUSTOM` branch.

**Priority 2 — React reconciliation & state:**

- Replace `key={cuid()}` with a stable id from the data in `Infobit/Group.jsx`, `Helpers/rendering.js`, and the footer maps across the card components — the single most impactful change.
- Stop mutating state/config in `Container.jsx` (`categoryHandler`, `authoredFilters` hashing) and inputs in `Helpers/Helpers.js` sort helpers; return new arrays/objects instead.
- Move `CardsCarousel.jsx`'s module-level `cardWidth`/`cardsShiftedPerClick` into component state/refs.

**Priority 3 — Dead code & disable hygiene:**

- Delete the empty `Modal/Icon.js` and `index.js`; remove or re-implement `polyfills.js` (and its no-op import in `app.jsx`); strip the Babel-verification `console.log` from `app.jsx`.
- Replace blanket `/* eslint-disable */` headers in `app.jsx`, `Modal/modal.js`, `Helpers/eventSort.js`, `Helpers/hooks.js` with targeted line/rule disables so the ruleset actually protects those files; migrate their `var` code to `const`/`let`.
- Remove redundant inline disables for globally-off rules (`max-len`, `no-restricted-syntax`, `no-plusplus`) via `eslint --report-unused-disable-directives`.
- Remove commented-out blocks (`Container.jsx:10,278`, `Grid.jsx:90`, `eventSort.js:248-254`, `withLinkTransformer.js:60-61`).

**Priority 4 — PropTypes & consistency:**

- Bring `CardFooter.jsx` propTypes/defaultProps up to its real prop surface; drop the extraneous props panels pass to `ClearButton`/`Group`.
- Add `displayName` to the five `forwardRef` filter components.
- Normalize `tabIndex` usage (string vs numeric; drop it from native buttons), fix copy-paste JSDoc headers, and move the hardcoded English aria strings in `Search.jsx`/`Sort/Popup.jsx` into i18n config.
