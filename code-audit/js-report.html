1. Summary

Against the project's configured Airbnb ruleset, the codebase is broadly clean and internally consistent — 56 of 108 files are Consistent, 17 are N/A (PropTypes shapes, constants, contexts, test fixtures, and vendored @dexter/ code), and only 9 are Inconsistent. The React component tree is disciplined: every component declares propTypes, defaultProps are paired wherever a prop isn't required, hooks are called unconditionally, and there is essentially no var, no loose ==, no unused/duplicate imports, and no array-index keys.

The real problems cluster in two areas: (1) entry/Modal utility files that ship blanket /* eslint-disable */ headers, empty dead files, and commented-out or debug code (app.jsx, modal.js, Modal/Icon.js, index.js, polyfills.js), and (2) a repeated key={cuid()} anti-pattern that mints a fresh React key every render. A handful of genuine latent bugs surfaced from close reading (a mis-typed config path, a double Date.parse, a permanently-dead debounce guard) matter more than any style nit.

The Consonant/** eslint override and global disables (no-console, max-len, no-plusplus, exhaustive-deps, subtree formatting rules) were honored — those are not flagged as violations.

2. Systemic & Recurring Issues

  1. key={cuid()} defeats React reconciliation. A brand-new random key every render → React remounts the whole list each time (losing DOM/focus state, hurting perf). Recurs in Infobit/Group.jsx (13 branches), Helpers/rendering.js (5 sites), and every card that maps a footer (BladeCard, BlogCard, EditorialCard, FlexCard, NewsCard, OneHalf, Product, TextCard). Highest-value fix.
  2. Blanket /* eslint-disable */ on authored, non-trivial files. app.jsx, Modal/modal.js (~377 lines), and Helpers/eventSort.js/Helpers/hooks.js (legacy var code) suppress the entire ruleset rather than the specific rule/line — hiding real issues. Distinct from the transpiled @dexter/ artifacts, where it's expected.
  3. Dead files and commented-out / debug code shipping in source. Empty 0-byte Modal/Icon.js and index.js (neither imported); polyfills.js is ~70 lines fully commented out yet still imported by app.jsx; app.jsx computes a "Babel 7 Upgrade Verified 🎉" object solely to console.log it; commented-out blocks in Container.jsx, Grid.jsx, eventSort.js, and // here markers in withLinkTransformer.js.
  4. Latent correctness bugs (not style). JsonProcessor.js:92 mis-typed path contentArea.dateTetailText (always ''); general.js:569 double Date.parse(...) → always NaN, dead branch; Modal/throttle.js re-declares timeout each call so the clear guard is permanently dead; CardFooter.jsx guards on if (new Date(cardDate)) which is always truthy; eventSort.js:127 returns an array where all other paths return an object.
  5. In-place mutation of state/config/inputs. Container.jsx mutates prior state in setFilters and the config-derived authoredFilters; Helpers.js sort helpers mutate the caller's array; CardsCarousel.jsx uses module-level mutable let shared across instances.
  6. CardFooter.jsx propTypes/defaultProps lag its prop surface. Validates only footerType's 5 fields while consuming ~12 props. Related: panels pass props children don't declare (panelHeader→ClearButton; isOpened/onClick/isTopFilter→Group).
  7. Redundant eslint-disable directives targeting globally-off rules (max-len, no-restricted-syntax, no-plusplus) — dead; eslint --report-unused-disable-directives would surface them.
  8. Cosmetic drift (low severity). Redundant tabIndex="0" on native buttons; mixed string vs numeric tabIndex; forwardRef without displayName (five filter files); copy-paste JSDoc drift; a few hardcoded English aria strings in an i18n-driven tree.

Priority 2 — React reconciliation & state

  • Replace key={cuid()} with a stable id in Infobit/Group.jsx, Helpers/rendering.js, and the card footer maps — the single most impactful change.
  • Stop mutating state/config in Container.jsx and inputs in Helpers/Helpers.js sort helpers; return new arrays/objects.
  • Move CardsCarousel.jsx's module-level cardWidth/cardsShiftedPerClick into component state/refs.

Priority 3 — Dead code & disable hygiene

  • Delete empty Modal/Icon.js and index.js; remove/re-implement polyfills.js (and its no-op import); strip the Babel-verification console.log from app.jsx.
  • Replace blanket /* eslint-disable */ headers (app.jsx, modal.js, eventSort.js, hooks.js) with targeted disables; migrate their var code to const/let.
  • Remove redundant inline disables for globally-off rules via eslint --report-unused-disable-directives.
  • Remove commented-out blocks (Container.jsx:10,278, Grid.jsx:90, eventSort.js:248-254, withLinkTransformer.js:60-61).

Priority 4 — PropTypes & consistency

  • Bring CardFooter.jsx propTypes/defaultProps up to its real prop surface; drop extraneous props passed to ClearButton/Group.
  • Add displayName to the five forwardRef filter components.
  • Normalize tabIndex usage, fix copy-paste JSDoc headers, move hardcoded English aria strings (Search.jsx, Sort/Popup.jsx) into i18n config.
